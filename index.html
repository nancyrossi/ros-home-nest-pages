ROS Home Nest

A personal home-automation client for one household Nest thermostat. It uses Google Device Access (Smart Device Management) so a local ROS 2 node can read climate status and apply mode, eco, fan, and setpoint commands.

This is not a public product or multi-customer service. Only the operator of this household authorizes access.

The client requests the https://www.googleapis.com/auth/sdm.service scope. Thermostat data stays on the household machine and local message bus. Nest cameras are not requested.
